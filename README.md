# Vedansh Sharma | Developer Portfolio 🚀

> A sleek, highly interactive personal portfolio built with Next.js. The design language is heavily inspired by Samsung's **One UI**, featuring deep soft shadows, frosted glassmorphism, precise squircle shapes, and smooth tactile animations.

## 🌐 Live Demo
Check out the live website: **[vedanshsharma.vercel.app](https://vedanshsharma.vercel.app/)**

## ✨ Key Features

- **Premium One UI Aesthetic:** Embraces Samsung's One UI philosophy with distinct "viewing" and "interactive" areas, massive squircles (`border-radius: 2rem+`), and diffuse drop shadows for a physical, floating feel.
- **Dynamic Micro-Interactions:** Tactile spring animations on buttons, cards that physically lift on hover, and custom thin translucent scrollbars.
- **Real-Time Coding Stats:** Fetches and displays live metrics from competitive programming profiles (LeetCode, CodeChef, and HackerRank) via a custom API route.
- **Project Showcase:** A centralized hub to display open-source projects, linked directly to their respective GitHub repositories.
- **Tech Stack Marquee:** A smooth, infinite-scrolling marquee highlighting the core technologies used in development.
- **Responsive Design:** Flawlessly adapts from massive ultra-wide monitors down to mobile screens.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VSDeadShot/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application running.
